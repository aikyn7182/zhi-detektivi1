# ЖИ детективі

4-сыныпқа арналған қазақ тіліндегі интерактивті сайт: тіркелу/кіру, оқушы мен мұғалім аккаунттары, үш деңгейдегі 15 тапсырма, жауаптарды бағалау, нәтижелер және мұғалім панелі.

## Іске қосу

1. Node.js 18+ орнатыңыз.
2. Терминалда жоба бумасын ашыңыз.
3. Мұғалім тіркелуі үшін код орнатыңыз:
   - Windows PowerShell: `$env:TEACHER_INVITE_CODE="ұзын-құпия-код"`
   - macOS/Linux: `export TEACHER_INVITE_CODE="ұзын-құпия-код"`
4. `npm start` деп жазыңыз (қосымша кітапханалар қажет емес).
5. Браузерден `http://127.0.0.1:3000` ашыңыз.

Алдымен мұғалім ретінде тіркеліп, содан кейін оқушылар жеке лақап аттарымен тіркеле алады. Оқушының нақты аты-жөні қажет емес.

## Маңызды шектеулер

Бұл — **толық жұмыс істейтін жергілікті демонстрациялық нұсқа**, бірақ сыртқы интернетте мектеп оқушыларымен пайдалануға қауіпсіздігін бөлек тексерусіз жариялауға арналмаған. Нақты жариялау үшін HTTPS, басқарылатын дерекқор, резервтік көшірме, rate limiting, құпиясөз қалпына келтіру, мұғалімдерді басқару, аккаунтты жою, деректер саясаты және қауіпсіздік тексерісі қажет. `data/db.json` ішінде парольдер scrypt көмегімен хэштеледі, алайда оқушылардың жауаптары мен лақап аттары сақталады. Құпия файлды ашық орналастырмаңыз.

ЖИ берген жауаптар нақты AI API-сынан алынбайды: педагогикалық мақсатта алдын ала әзірленген. Тексеру ұпайы — екі жабық сұрақтан (0–2); оқушының мәтіндік дәлелін мұғалім өзі бағалайды. Нақты зерттеудің қорытындысы ретінде демонстрациялық деректерді пайдалануға болмайды.

## Сервер параметрлері

- `PORT` — порт (әдепкі 3000)
- `HOST` — адрес (әдепкі 127.0.0.1)
- `TEACHER_INVITE_CODE` — мұғалім тіркелу коды
- `DATA_DIR` — деректер папкасы
- `COOKIE_SECURE=true` — HTTPS қолданғанда Secure cookie

Мұғалімнің кодын оқушылармен бөліспеңіз.
